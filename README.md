## Previewing the Website

To preview the website, follow these steps:

1. Open the repository in Visual Studio Code.
2. Build the project by running the `build` task defined in `.vscode/tasks.json`.
3. Launch the website by running the `.NET Core Launch (web)` configuration defined in `.vscode/launch.json`. This will start the ASP.NET Core application and open a web browser to preview the website.
4. Alternatively, you can use the `watch` task defined in `.vscode/tasks.json` to automatically rebuild and run the project whenever changes are made. This will also launch the website in a web browser for preview.
